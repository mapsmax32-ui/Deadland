# DEADLAND 3D models

Put exported Blender **.glb** files here or in the subfolders below.

- `characters/` — survivor, zombie, stranger
- `environment/` — buildings, cars, props

See [`docs/BLENDER_GODOT.md`](../../docs/BLENDER_GODOT.md) for export and import steps. GLB files are not committed yet; the current scene still uses procedural placeholder geometry until model instances are wired into `scripts/main.gd`.
