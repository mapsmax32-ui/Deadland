# Blender → Godot для DEADLAND

## Принятый формат
Используем **glTF 2.0 Binary (.glb)**: один файл может содержать сетку, материалы, текстуры и скелет/анимации. Godot 4.3 импортирует GLB прямо из проекта.

## Папки проекта
- `assets/models/characters/` — игрок, зомби, NPC (.glb)
- `assets/models/environment/` — здания, машины, декорации (.glb)
- `assets/materials/` — дополнительные материалы/текстуры, если они не упакованы в GLB

Положи экспортированные файлы в эти папки внутри проекта Godot. После копирования Godot автоматически импортирует их; затем открой сцену и проверь модель.

## Экспорт из Blender
1. Открой модель и примени трансформации: Object Mode → Ctrl+A → Rotation & Scale.
2. Для персонажа проверь, что модель смотрит вдоль **-Z** (обычное направление вперёд в Godot), ноги стоят на уровне Z=0? В Blender пол — плоскость **XY**, вертикаль — **Z**; при экспорте glTF координаты автоматически конвертируются для Godot, поэтому просто поставь ноги на пол и не меняй оси вручную.
3. File → Export → glTF 2.0 → формат **glTF Binary (.glb)**.
4. Включи Selected Objects, если нужно экспортировать только выбранную модель. Для персонажей экспортируй mesh и armature вместе; включи анимации, если они есть.
5. Сохрани файл с понятным именем, например `survivor.glb`, `zombie.glb`, `stranger.glb`, `abandoned_car.glb`.

## Импорт и проверка в Godot
1. Скопируй .glb в соответствующую папку проекта.
2. Дождись окончания импорта в Godot FileSystem.
3. Перетащи GLB в тестовую сцену. Проверь размер, направление, материалы и анимации.
4. Для игрового персонажа оставь физику/коллизии в Godot: GLB — визуальная модель, а CharacterBody3D и CollisionShape3D отвечают за движение и столкновения.

## Важно для текущей версии
Сейчас `scripts/main.gd` создаёт персонажей и окружение процедурно из примитивов. Добавление GLB в папку само по себе **не заменит** эти фигуры. Следующий этап — подключить конкретные модели по согласованным именам и сохранить игровые узлы, коллизии, управление и логику. Пока GLB-файлы не добавлены, текущая сцена продолжит работать как раньше.

## Чек-лист качества
- масштаб в метрах; рост человека примерно 1.7–1.9 м
- применены Rotation & Scale
- материалы/текстуры включены в .glb, где возможно
- сетка не слишком тяжёлая для целевого ПК
- персонажи экспортированы вместе со скелетом и нужными анимациями
