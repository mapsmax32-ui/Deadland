# DEADLAND — Последний рубеж

Мобильный 3D-прототип зомби-выживания для Android. Сейчас это ранний прототип: простая изометрическая сцена, сенсорный джойстик, кнопки действий, преследующий зомби и сюжетный выбор при встрече с незнакомцем.

## Как получить APK

GitHub Actions запускает облачную сборку при каждом push в `main` и вручную.

1. Открой вкладку **Actions** репозитория.
2. Выбери **Build DEADLAND Android APK** и открой последний запуск.
3. Дождись зелёной галочки.
4. Внизу страницы запуска скачай артефакт **DEADLAND-Android-APK**.
5. Распакуй ZIP и установи APK на Android. При необходимости Android попросит разрешить установку из этого источника.

Если сборка завершилась ошибкой, открой лог задания и пришли скриншот или текст ошибки.

## Управление

- Джойстик слева — движение.
- **ДЕЙСТВИЕ** — поговорить с незнакомцем рядом.
- **УДАР** — атаковать зомби на близком расстоянии.

Это ещё не полноценная коммерческая игра и APK не считается готовым, пока облачная сборка не завершилась успешно. Визуальные модели, анимации, инвентарь, сохранение и дополнительные главы предстоит добавить.
